# Japanese Dictionary Skill

避免中→日轉換時最常見的兩種錯誤：

1. **漢字誤判**：中文漢字長得像日文但日文不用，或日文用不同字形。
   例：中文「打印」≠ 日文「印刷」；中文「電腦」≠ 日文「パソコン／コンピュータ」。
2. **讀音標錯**：同一漢字在日文有多個音讀/訓讀，複合詞讀法常不直觀。
   例：「言葉」唸 ことば，不是 げんよう；「今日」唸 きょう，不是 こんにち（こんにち 是另一個意思）。

## 何時啟動

- 使用者要求中→日翻譯（句子、術語、PPT 內容）
- 使用者問「○○ 的日文是？」「振り仮名」「ふりがな」「讀音」「読み方」
- 使用者問「○○ 是日文嗎」「日本人會這樣寫嗎」
- 使用者貼日文段落要求標讀音或檢查
- 在你（Claude）即將輸出日文內容、但對任何漢字寫法或讀音不是百分之百確定時 — 主動啟動

## 線上查詢工具（runtime 呼叫）

優先用 Bash + curl；若 curl 不可用，改用 WebFetch。

### 1. jisho.org API（主要：詞彙查詢）

```
GET https://jisho.org/api/v1/search/words?keyword=<URL-encoded query>
```

回傳 JSON。需要關注的欄位：

- `data[].japanese[].word` — 漢字寫法
- `data[].japanese[].reading` — 假名讀音（核心！）
- `data[].senses[].parts_of_speech` — 詞性
- `data[].senses[].english_definitions` — 英文釋義（理解語意用）
- `data[].is_common` — 是否常用詞（重要過濾）

### 2. kanjiapi.dev（漢字級驗證）

```
GET https://kanjiapi.dev/v1/kanji/<single-kanji>
```

- 200 → 該漢字在日文有定義，回傳 `kun_readings`、`on_readings`、`meanings`、`jlpt`、`grade`
- 404 → 該字**不在常用日文漢字表（常用漢字 + 人名用漢字 + JIS）**，很可能是：
  - 中文專用字形（例：「么」「锅」「闹」）
  - 簡體字（日本不用簡體）
  - 繁體中文獨有的字形（例：「臺」日文多用「台」）

### 3. 日文 Wiktionary（補充：古語、罕用詞、異體字）

```
GET https://ja.wiktionary.org/w/api.php?action=query&prop=extracts&titles=<word>&format=json&explaintext=1&exintro=1
```

當 jisho 沒收錄時使用。

## 標準工作流程

1. **拆解輸入**：把待查內容切成詞與單字。複合詞先整詞查；查無再拆。
2. **逐詞查 jisho**：
   - 有結果且 `is_common: true` → 取讀音、標為「常用」
   - 有結果但非常用 → 取讀音、註記「較少用，視語境」
   - 無結果 → 進入步驟 3
3. **逐字查 kanjiapi.dev**：
   - 全部 200 → 字都在日文裡，但組合可能不成詞 → 改寫法（如改假名）或查 Wiktionary
   - 任一 404 → **明確回報「此漢字非日文常用字，疑似中文專用字形」**，建議日文對應寫法
4. **回報結果**（見下節格式）

## 輸出格式

每詞一行：

```
言葉 → ことば（常用・名詞）
```

多種讀法 → 全列，標註情境：

```
日本 → にほん（一般）／にっぽん（正式場合、體育賽事、貨幣）
```

有疑慮 → 用 ⚠️ 並提供替代：

```
打印 → ⚠️ 日文無此詞。「打印」在中文是「列印」，日文用「印刷（いんさつ）」或カタカナ「プリント」。
```

完全找不到 → ❌ 並坦白：

```
○○○ → ❌ jisho、Wiktionary 均無此條目。可能是中文詞彙、新造詞或拼寫錯誤。
```

## 絕對規則

1. **不憑空產生讀音**。沒查到就說沒查到。不靠「看起來像」猜測。
2. **不直接貼 API 整段回應**到對話。萃取讀音、詞性等必要欄位，用自己的話組織。
3. **漢字字形分歧時**（如「弁当 / 辨當」、「学校 / 學校」、「会社 / 會社」），一律用日文新字體（常用漢字表內的字形）。如果使用者貼的是繁體字形，自動換成日文新字體再查。
4. **人名地名標記**：jisho 結果若 `parts_of_speech` 含 "Place"、"Full name"、"Surname"、"Given name"，要提醒「此讀音為專有名詞用，一般詞彙意義可能不同」。
5. **網路受限時誠實說明**：若 API 都打不通，明說「無法即時查證，以下讀音僅憑模型記憶，建議用 jisho.org 雙重確認」，不要假裝有查。
6. **複合詞優先整體查**：「出張」整詞查比「出」「張」分開查可靠。連濁、音便等變化只有整詞才看得出來。

## 範例：完整流程

**使用者**：把「我下星期要去日本出差，討論新產品的功能規格」翻成日文，附假名。

**Claude 內部流程**：
1. 草擬譯文：「来週、日本へ出張に行き、新商品の機能仕様について話し合います。」
2. 對每個漢字詞用 Bash 平行查 jisho：
   - `curl -s 'https://jisho.org/api/v1/search/words?keyword=%E6%9D%A5%E9%80%B1'` → らいしゅう
   - `curl -s 'https://jisho.org/api/v1/search/words?keyword=%E5%87%BA%E5%BC%B5'` → しゅっちょう
   - 「新商品」「機能」「仕様」「話し合う」… 逐一查
3. 任何 404 或 jisho 無結果 → 拆字用 kanjiapi.dev 驗證
4. 回覆：
   > 来週（らいしゅう）、日本（にほん）へ出張（しゅっちょう）に行（い）き、新商品（しんしょうひん）の機能（きのう）仕様（しよう）について話（はな）し合（あ）います。

## 範例：偵測中文誤用

**使用者**：日文「視頻」怎麼讀？

**Claude 流程**：
1. jisho 查「視頻」→ 通常無結果或非常用
2. kanjiapi 查「頻」→ 200（日文有此字，唸 ヒン）
3. 判斷：兩字都在日文但組合不通用 → 這是中文簡體用語
4. 回覆：
   > ⚠️「視頻」是中文（影片）的說法，日文不使用此詞。日文對應為「動画（どうが）」或カタカナ「ビデオ」。

## 範例：偵測中文專用字形

**使用者**：「臺灣」的日文讀音？

**Claude 流程**：
1. jisho 查「臺灣」→ 無 / 罕用
2. kanjiapi 查「臺」→ 多半 404 或標為非常用
3. 改用日文新字體「台湾」再查 → タイワン（一般カタカナ表記）或 たいわん
4. 回覆：
   > 日文寫作「台湾（たいわん／タイワン）」。新字體用「台」非繁體「臺」。
